🎯 Insight: Race Condition UI

State toggle tidak sinkron karena:

  1. Event handler async yang lambat (setTimeout)
  2. Update UI dan state terpisah
  3. Klik cepat menyebabkan state tertukar
// KODE BURUK - Race Condition!
let state = false;

async function toggle() {
  // Simulasi proses async
  await new Promise(r => setTimeout(r, Math.random() * 200));
  state = !state;
  // Update UI terlambat
  updateUI();
}
